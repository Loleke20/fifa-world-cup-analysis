FIFA World Cup Historical Data Analysis

Overview:

This project's main duty is to analyze historical FIFA World Cup tournaments data by using Python, Pandas, and Matplotlib

The main goal is to explore and analyze the scoring trends and the history over time of the World Cup

Questions:

How has tournament scoring changed over time?

How many goals were scored across the tournaments in the dataset?

Which World Cups had the most goals?

Tools:

Python

Pandas

Matplotlib

Pycharm

Analysis:

The project uses Pandas to analyze and load tournament-level World Cup data.

The analysis include:

Total goals

Average goals per tournaments

Scoring trends over time

Championship counts by country

Matplotlib is used to create the visualization to show the total amounts of goals per tournament year and World Cup championships by Country.

Skills Demonstrated:

Python programming

Pandas DataFrames

Data aggregation

Descriptive statistics

Data visualization

Working with CSV datasets

Data:

The dataset contains tournament-level information including World Cup year, champion, runner-up, third-place team, host country, and total tournament goals

The project is intended to be for an educational portfolio project.
